# making.nj.friend

능친 만들기 — 친구 매칭·채팅 데스크톱/웹 앱

## 로컬에서 실행

- **데스크톱 앱**: `python main.py`
- **웹 버전(로컬)**: `streamlit run streamlit_app.py` → 브라우저에서 http://localhost:8501

## 웹 주소로 인터넷에서 쓰기

로컬만 쓰면 **"https://어떤주소.com"** 같은 웹 주소는 없습니다.  
웹에서 쓰려면 **Streamlit Cloud** 등에 배포해야 합니다.

- **배포 방법**: 프로젝트 폴더 안의 **`웹_배포_안내.md`** 참고
- 배포 후 예시 주소: `https://making-nj-friend-xxxx.streamlit.app`
